# 🎬 Katalog Cinema - Web Catalog Film

Proyek web katalog film interaktif yang dibangun menggunakan HTML5 dan CSS3 murni. Didesain dengan antarmuka modern (dark theme) untuk memberikan pengalaman menjelajah katalog film yang nyaman.

## 🚀 Live Demo
Tampilan web yang sudah di-deploy dapat diakses melalui link berikut:
👉 [Katalog Cinema Live](https://fasha54.github.io/katalog-cinema/)

---

## 🛠️ Fitur Utama
- **Halaman Utama (`index.html`)**: Menampilkan daftar katalog film terkini dengan kartu visual interaktif.
- **Halaman Kontak (`kontak.html`)**: Formulir interaktif untuk menghubungi admin/dukungan.
- **Halaman Profil (`profil.html`)**: Informasi pengembang dan deskripsi proyek.
- **Responsive & Dark Mode Layout**: Styling khusus menggunakan CSS (`style.css`) dengan estetika platform streaming modern.

---

## 🧰 Teknologi yang Digunakan
- **HTML5**: Struktur halaman web.
- **CSS3**: Layouting, styling, dan animasi transisi.
- **GitHub Pages**: Layanan hosting publik.
